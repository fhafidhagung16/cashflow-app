# CashFlow : Personal Finance Management

A simple and responsive personal finance management application built to help users track income, expenses, and balance in one place.

## Overview

CashFlow is a web application project focused on personal financial management. It provides a simple dashboard for recording transactions and monitoring financial summaries.

This project is part of my journey as an Informatics student, where I practice web development and JavaScript programming.

## Features

- **Financial Dashboard** : View balance, income, and expenses.
- **Transaction Management** : Add and delete financial transactions.
- **Automatic Calculation** : Update financial summaries based on transactions.
- **Data Persistence** : Keep transaction data available after refreshing or reopening the browser.
- **Responsive Interface** : Designed for convenient use on different screen sizes.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage *(if used by the current implementation)*

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Start adding income and expense transactions.

No additional dependencies are required for the basic version.
